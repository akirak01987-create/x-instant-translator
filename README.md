# X 即時翻訳（Android）

X公式アプリの通知をAndroidの `NotificationListenerService` でイベント受信し、英語通知をML Kitで端末内翻訳して日本語通知として表示します。Android Studioは不要で、GitHub ActionsがビルドしたAPKをスマホに直接インストールできます。

## APKの入手方法（Android Studio不要）

1. GitHubリポジトリの **Actions** タブを開く
2. 一番上にある `Android Debug APK Build` ワークフローの実行結果（緑のチェック）を開く
3. 画面下部の **Artifacts** に表示される `XInstantTranslator-debug-apk` をスマホでダウンロード（zip形式）
4. ダウンロードしたzipを展開すると `app-debug.apk` が出てくるので、スマホ側で開いてインストール
   - 「提供元不明のアプリ」の許可を求められた場合は許可してください

`main` ブランチや作業ブランチにpushするたびに、GitHub Actionsが自動でdebug APKをビルドします。

### 重要：今回だけ一度アンインストールしてから入れ直してください

以前のビルドはCI実行のたびにランダムなデバッグ署名鍵が使われており、APKを入れ替えるたびに署名が変わって「通知へのアクセス」権限や保存データが毎回リセットされる原因になっていました。今回、リポジトリに固定の署名鍵を同梱し、以後のビルドは常に同じ署名になるよう修正しました。

- **今回の更新のみ**：一度アプリをアンインストールしてから、新しいAPKを入れ直してください（署名が変わるため上書きインストールができません）。
- **次回以降**：署名が固定されるため、新しいAPKを上書きインストールしても「通知へのアクセス」権限や履歴・フィルターのデータは消えなくなります。

## 初回設定

1. 上記の手順でAPKをスマホにインストール
2. アプリを開き、通知の送信を許可
3. 「通知へのアクセスを許可」から「X即時翻訳」をオン
4. 「翻訳モデルを準備」を押す（初回のみ約30MB）
5. Androidのアプリ情報で、可能ならバッテリー使用量を「制限なし」に設定

## 画面構成

下部ナビゲーションで3画面を切り替えます。

- **通知履歴**: 受信した投稿を新しい順に一覧表示（受信日時・投稿者・原文・日本語訳）。項目タップで元のX投稿（アプリ稼働中はその投稿、再起動後などは代わりにXアプリ）を開きます。個別削除・全件削除に対応し、端末再起動後も履歴は保持されます。保存期間は「アプリ設定」画面から分単位で変更可能（初期値1440分＝1日）。
- **フィルター設定**: 投稿者や本文キーワードでフィルターを登録・編集・削除・並べ替えできます。上にあるフィルターほど優先され、最初に一致したフィルターの設定（翻訳可否・ポップアップ表示・通知音・アプリ内の文字色/背景色）が適用されます。どのフィルターにも一致しない通知は「デフォルト設定」に従います。フィルター編集画面では色をパレットから選び、保存前にプレビューできます。
- **アプリ設定**: 通知アクセスの許可、翻訳モデルの準備、保存期間の変更、直近の受信ログ（診断用）の確認などを行います。

## 動作上の注意

- 1秒ごとのポーリングではなく、X通知がAndroidに届いた瞬間のイベントで動作します。
- X側の配信遅延や、X公式アプリで届かなかった通知は取得できません。
- 英語と判定した投稿のみ翻訳対象です（フィルターで個別に翻訳のオン/オフも可能）。日本語の投稿もフィルター条件に応じて履歴に保存されます。
- 通知音の有無・ポップアップの表示有無はAndroidの通知チャンネル仕様に沿って分離しており、無音設定では音・バイブレーションとも鳴りません。
- 翻訳・履歴・フィルターのデータはすべて端末内（Room/SQLite）に保存され、外部サーバーへは送信しません。アプリ更新後もデータは保持されます。
- 同一投稿は自動的に重複排除され、履歴に二重保存されません。

## 対応

- Android 8.0（API 26）以降、Android 16でも動作します。
- X公式アプリ（`com.twitter.android`）およびX Lite
